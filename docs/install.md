# Installation

## Prérequis

Avant de commencer, vérifiez que les outils suivants sont installés :

- **Git**
- **Docker**
- **Docker Compose**
- une clé SSH configurée pour les repositories Afendar

## Cloner le projet

Clonez le repository principal avec ses submodules :

```bash
git clone --recurse-submodules git@github.com:Afendar/afendar-games.git
cd afendar
```
